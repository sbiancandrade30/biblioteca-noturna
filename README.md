# Biblioteca Noturna

Página responsiva para organizar o próximo encontro do Clube do Livro Biblioteca Noturna.

## O que já funciona

- Seleção de nome entre as participantes cadastradas.
- Escolha dos dias disponíveis no calendário.
- Resumo dos dias mais votados.
- Visual adaptado para celular e computador.

## Próximas etapas

1. Conectar os votos ao Firebase.
2. Publicar o site no Firebase Hosting.
3. Adicionar as demais páginas do clube sem refazer esta base.

## Teste local

Abra `index.html` no navegador ou execute um servidor local na pasta do projeto.
